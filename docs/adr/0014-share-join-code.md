# ADR 0014: 비공개 방 참가 코드 복사·공유

## 상태
채택 (2026-10). 코어 규칙·모델·화면(Robolectric)에서 검증했다. 공유 시트와 클립보드의 실제 동작은 실기기 확인 전이다.

## 결정
1. **대기실의 코드 줄**(비공개 방, 방 안의 누구나): 코드 + "복사" + "공유". 복사는 코드만 클립보드에 넣고(성공/실패를 라이브 영역으로 알린다 — 일부 기기는 쓰기를 막는다),
   공유는 `ACTION_SEND` 공유 시트에 **방 이름과 코드가 든 메시지**("Coup 방 '…'에 들어오세요!\n참가 코드: XXXXXX", 영어는 "Join code: XXXXXX")를 넘긴다.
   기기 밖으로 내보내는 일은 `CodeSharer` 인터페이스 뒤에 두었다(`AndroidCodeSharer` / 테스트의 가짜). 제공되지 않으면 버튼 없이 코드만 보인다.
2. **받는 쪽**: 로비의 코드 칸에 공유 메시지를 **통째로 붙여 넣어도** 코드만 남는다. 코어 `JoinCodes.extract(text)`는 글 전체가 코드이거나, "코드:/code:" **이름표 뒤의 6글자**가 코드 모양일 때만 읽는다.
   이름표 없이 글 속의 6글자를 읽으면 평범한 영어 단어(`PRIVATE`, `JOINME2`)를 코드로 착각하므로 읽지 않는다. `LobbyModel.joinByCode/isCodeComplete`도 같은 추출을 쓴다.
3. 링크(딥링크/앱 링크)는 넣지 않았다 — 도메인 검증과 `assetlinks.json` 배포가 필요하고 오너 작업이 따른다. 후속.

## 검증
- 코어 `JoinCodes.extract` 1(코드 자체·한/영 이름표·전각 콜론·이름표 없는 영어 단어 거절·잘못된 모양 거절), `LobbyModel` 1(메시지를 통째로 붙여 입장).
- 화면 6: 복사(코드만 들어감, 알림), 복사 실패 안내, 공유 메시지(방 이름·코드 포함, 다시 추출 가능), 공유 수단 없음, 공개 방에는 없음, 로비 붙여 넣기 -> 코드만 남고 입장. 변이 6종 검출.

## 한계
- 코드는 방 문서에 평문이다(방 안의 사람은 누구나 읽는다 — 기존 설계). 방이 닫히면 풀린다. 코드 재발급·만료는 없다.
- 공유받은 사람이 앱이 없으면 코드만으로는 설치로 이어지지 않는다(딥링크 후속).
