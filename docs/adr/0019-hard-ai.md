# ADR 0019: HARD AI — 결정화 몬테카를로

## 상태
채택 (2026-10). 오너 요청("HARD AI 진행하자"). 설계 §7.5의 "결정화 샘플링 + NORMAL 정책 롤아웃"을 따르되, 측정으로 롤아웃 길이·사전값·상대 모델을 정했다.

## 결정
1. **치팅 없는 시뮬레이션**: 결정마다 뷰와 공개 주장 기록에서 상대 손패·덱 순서를 뽑고(`HiddenSampler`), `engine.determinize`로만 시뮬레이션 상태를 만든다.
   표본은 미확인 풀(덱 구성 − 내가 본 카드)을 섞어 나누되, 상대가 지금도 들고 있다고 주장한 역할은 `1 − 관찰된 블러핑 비율`의 확률로 먼저 쥐여 준다.
   AI 소스는 여전히 `GameState`를 이름으로도 참조하지 않는다(정적 검사 통과). 뷰 동치 테스트(같은 뷰 → 같은 결정)가 HARD에도 적용된다.
2. **탐색**: 후보 수(행동×대상 상위 2, 응답, 공개/상실 카드의 역할별, 교환의 역할 구성별)마다, 같은 표본 집합에서 그 수를 적용한 뒤
   휴리스틱 정책으로 **14결정**(또는 판 끝)까지 두고 보상(우승 1, 순위 몫, 안 끝났으면 영향력·코인 형세의 몫 × 0.8)을 평균한다.
3. **사전값**: NORMAL 정책이 고른 수에 평균 보상 +0.03. 표본이 적을 때 우연한 차이로 검증된 휴리스틱을 뒤집지 않게 한다.
4. **상대 모델 섞기**: 시뮬레이션 속 상대를 표본마다 균형 50% / 공격 15% / 신중 15% / 무작위 20%로 뽑는다(같은 표본의 모든 후보가 같은 상대를 만난다).
5. **예산**: 표본 40개, 결정당 400ms 상한(그래도 최소 4개는 끝낸다). 스레드 인터럽트 시 최소 표본 뒤 멈춤. 고를 수가 하나뿐이면 탐색하지 않는다.
   표본이 하나도 안 되면(뷰 모순 등) NORMAL의 선택을 낸다. 시간 상한에 닿지 않으면 같은 seed는 같은 결정을 낸다.

## 측정 (이 개발 머신, 판 수 120~200, 1명의 HARD 대 나머지)
| 설정 | 상대 NORMAL 4인 | 상대 무작위 4인 |
|---|---|---|
| 끝까지 롤아웃(80결정), 표본 24, 사전값·섞기 없음 | 0.47 | 0.51 |
| 롤아웃 14, 표본 16, 사전값 0 | 0.54 | 0.62 |
| 롤아웃 14, 표본 16, 사전값 0.03 | 0.63 | 0.76 |
| **롤아웃 14, 표본 40, 사전값 0.03 (기본)** | **0.69** | **0.84** |

기본 설정의 NORMAL 상대 승률: 2인 0.71(기준선 0.50), 3인 0.75(0.33), 4인 0.69(0.25), 6인 0.51(0.17). 결정당 평균 ~30ms, 최대 ~0.4s(상한 이전).
- **발견**: 판 끝까지 두는 롤아웃은 오히려 약했다 — 판의 우연이 후보 간 작은 차이를 덮는다(분산). 너무 짧은 롤아웃(3결정)도 형세 평가의 오차로 약했다.
- NORMAL만 가정한 시뮬레이션은 NORMAL을 잘 이기지만 다른 부류의 상대(무작위)에게 약했다(과적합). 섞기와 사전값이 그 격차를 줄였다(NORMAL 자신은 무작위 상대 0.86).

## 다른 선택지
- **ISMCTS**(정보 집합 트리 탐색): 더 강할 수 있지만 구현·튜닝 비용이 크고, 이 판 길이에서는 1단 탐색 + 짧은 롤아웃으로 충분한 개선을 얻었다.
- **상대 행동으로 상대 모델 학습**(관찰된 도전·막기 빈도): 후속 개선 후보.

## 검증
- 단위 테스트: 표본 세계가 원래 뷰와 같게 보임(교환 중 포함), 주장 반영, 탐색 예산(정확한 표본 수·상한·최소 표본·인터럽트), 단일 후보, 실패 시 NORMAL의 선택,
  후보 생성(위협 순 대상·교환 조합·응답), 보상 값, 주장 기록 복사, 사전값(크면 NORMAL과 같음/없으면 뒤집을 수 있음), 재현성, 무작위·NORMAL 상대 강도.
- 기존 테스트가 HARD를 포함한다: 뷰 동치 1,000결정 이상, 하우스룰 조합 포함 1만 결정 합법성(HARD 한 자리 + NORMAL).

## 결과와 한계
- 느린 기기에서는 상한 때문에 표본이 줄어 약해진다(최소 4표본). 측정치는 이 개발 머신 기준이다.
- 시뮬레이션은 판의 우연을 평균하므로, 한 판 단위로는 NORMAL에게 질 수 있다(4인전 3할).
- 시뮬레이션 속 상대 섞기 비율과 사전값은 측정 노이즈(±0.03~0.04) 안에서 정했다.
